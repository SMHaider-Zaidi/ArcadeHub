# ArcadeHub 🕹️
ArcadeHub is a simple website for playing browser-based games. It uses a Python (Flask) backend to manage the pages and JavaScript to power the actual gameplay.

### 🎮 Games Included
Road Rush: A car racing game built with JavaScript.<br>
Tic-Tac-Toe: A classic 2-player logic game.

### 🛠️ Built With

Python (Flask): Handles the backend and page routing.<br>
JavaScript: Powers the game logic and interactivity.<br>
HTML/CSS: Used for the structure and styling.

### ⚙️ How to Run
Clone the repository:
git clone https://github.com/SMHaider-Zaidi/ArcadeHub.git

### Install Flask:
pip install flask

### Run the app:
python app.py
