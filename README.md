ArcadeHub 🕹️
A simple Flask-based web application to host and play JavaScript games.

🎮 Games Included
Road Rush: A car racing game built with JavaScript.
Tic-Tac-Toe: A classic 2-player logic game.

🛠️ Built With
Python (Flask): Handles the backend and page routing.

JavaScript: Powers the game logic and interactivity.

HTML/CSS: Used for the structure and styling.

📂 Project Structure
static/: Contains images and CSS files.

templates/: Contains HTML files for each page.

app.py: The main Flask script to run the server.

⚙️ How to Run
Clone the repository:
git clone https://github.com/SMHaider-Zaidi/ArcadeHub.git

Install Flask:
pip install flask

Run the app:
python app.py

Open http://127.0.0.1:5000 in your browser.
